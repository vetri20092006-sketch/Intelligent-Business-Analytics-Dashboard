About OmniMetrics AI Platform

An end-to-end Machine Learning intelligence framework designed to bridge the gap between predictive statistical modeling and actionable executive decision-making.

Project Objectives & Scope

Mini-Project

In modern SaaS and enterprise subscription business models, customer acquisition costs continue to climb. Retaining high-value accounts requires shifting from reactive customer support to predictive customer success.

OmniMetrics was engineered as a production-grade machine learning platform that ingests high-dimensional telemetry, contract parameters, and friction indicators. Rather than outputting an opaque probability score, it provides transparent feature attribution and prescriptive interventions.

How to Replace Dataset & Custom Trained Model (.pkl)

Developer instructions for swapping in your own dataset and trained pipeline

Developer Guide

Step 1: Replace the Dataset File

Copy your custom CSV dataset into the data/ directory.

# Replace target CSV at:
data/business_analytics_dataset.csv

Step 2: Drop In Your Trained Pickle Model (.pkl)

Export your scikit-learn model, XGBoost, or custom Pipeline using joblib.dump(model, "models/model.pkl") and place it in the models/ directory:

# Place trained model file at:
models/model.pkl

Step 3: Update Feature Names in config.py (If Features Differ)

If your dataset has different feature column names, simply update the feature lists in config.py:

# In config.py:
REQUIRED_NUMERIC_FEATURES = [
    "your_feature_1", "your_feature_2", ...
]
REQUIRED_CATEGORICAL_FEATURES = [
    "your_category_1", ...
]

Step 4: Re-generate Metrics (Optional or Automated)

You can run python train_model.py at any time to automatically retrain the pipeline on your new dataset, update the ROC curves, and refresh the confusion matrix JSON cached at models/metrics.json.
