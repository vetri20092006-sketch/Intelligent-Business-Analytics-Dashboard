Knowledgebase
How do I plug in my own trained machine learning model (.pkl)?
Save your trained scikit-learn pipeline or classifier using joblib.dump(model, "models/model.pkl") and replace the file at models/model.pkl. When app.py runs, it automatically loads this file at startup into memory.
What if my dataset has different columns or features?
Open config.py and update the REQUIRED_NUMERIC_FEATURES and REQUIRED_CATEGORICAL_FEATURES lists. Then update the input form in templates/prediction.html to match your new fields.
Is any external cloud connection or paid API required?
No. OmniMetrics is 100% self-contained. Predictions run locally inside your Python runtime via scikit-learn and Flask. No external API keys or cloud subscriptions are needed.
How are the prescriptive recommendations generated?
The backend features a rule-based prescriptive engine in app.py that analyzes the predicted churn probability alongside specific client friction triggers (such as high support tickets, low product usage score, or payment delay days) to formulate immediate countermeasures.
